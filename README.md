# Snapa — статический снимок Webflow-сайта

Полная статическая копия [snapa.webflow.io](https://snapa.webflow.io/), снятая 2026-08-07.
Все изображения, шрифты и внутренние JS-чанки Webflow скачаны и лежат локально в `assets/`
— сайт не зависит от хостинга/CDN Webflow. Внешние библиотеки (GSAP, jQuery через CDN,
Lenis) остаются подключены как есть, как и на оригинале.

## Известное ограничение

**Форма заказа не отправляется.** На оригинале форма уходит на бэкенд Webflow —
вне Webflow-хостинга это не работает без отдельного бэкенда (например, Formspree
или свой сервер). Визуально форма на месте, но сабмит никуда не долетит, пока не
подключим альтернативу.

## Структура

```
index.html
assets/
  css/    — стили (Webflow-сгенерированный CSS)
  images/ — все изображения, фавиконы
  fonts/  — кастомные шрифты (General Sans, Kobzarks)
  js/     — jQuery + внутренние JS-чанки Webflow
```

Кастомная логика анимаций (прелоудер, скролл-эффекты) вшита прямо в `index.html`
как inline `<script>` — это тот же код, что живёт в Custom Code проекта на Webflow.
